## Source of truth

When documents conflict, use this order:

1.  Current source code
2.  `README.md`
3.  `PROJECT_CONTEXT.md` and `ARCHITECTURE.md`
4.  Specialized technical documents
5.  Roadmap/TODO documents
6.  Historical notes

`Project Markdown.md` at the repository root is retained only as a
historical pointer and is not current project planning.
